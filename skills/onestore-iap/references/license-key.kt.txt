package __PACKAGE__

/**
 * 원스토어 라이선스 공개키를 제공합니다.
 *
 * **공개키를 소스에 평문 문자열로 두지 마세요.** 공개 문서의 「결제 테스트 및 보안」이 명시합니다 —
 * "공개 키라 할지라도 앱 코드 안에 일반 문자열로 넣는 것은 안전한 방법이 아닙니다."
 * 평문 상수는 APK의 문자열 목록에 그대로 노출되어 바꿔치기 대상이 됩니다.
 *
 * ## 어디에 두는 것이 나은가 (위가 안전)
 * 1. **개발사 서버가 내려준다** — 앱에 키가 없는 것이 가장 안전합니다. 공개 문서의 권고이기도
 *    합니다("공개 키 등은 서버에서 보관")
 * 2. **XOR로 감싸 소스에 둔다 + 난독화** — 이 파일의 기본 구현입니다. 공개 문서가 제시하는 방법이고,
 *    평문 문자열이 APK에 남지 않습니다
 * 3. `BuildConfig` 필드로 빼기 — 저장소에는 안 남지만 **APK에는 평문으로 들어갑니다.** 키를 소스
 *    관리에서 빼는 효과까지입니다
 *
 * **어느 방법도 앱 안의 검증을 안전하게 만들지는 못합니다.** 키를 바꿔치기하거나 검증을 건너뛰도록
 * APK를 패치하는 것은 막을 수 없습니다. 그래서 **서버가 상품을 지급하는 구조라면** 서버의 영수증
 * 검증이 실제 방어선이고, 키 은닉은 그 위에 얹는 보조 수단입니다. 서버가 없는 앱이라면 키 은닉과
 * 난독화가 앱단에서 할 수 있는 전부입니다.
 *
 * ## 채우는 방법
 * [ENCODED]와 [MASK]는 **평문 키를 XOR로 인코딩한 값**입니다. 손으로 만들지 말고 연동을 도운
 * 도구에 "이 키로 채워 달라"고 맡기세요 — 인코딩 후 되돌린 값이 원본과 같은지 대조까지 해야 합니다.
 * 값이 틀리면 컴파일은 되고 **결제만 조용히 실패**합니다.
 *
 * 릴리즈 빌드에는 난독화(Proguard/R8)를 함께 적용하세요.
 */
internal object OneStoreLicenseKey {

    /**
     * XOR로 인코딩된 공개키.
     *
     * TODO: 개발자센터 공통정보 → 라이선스 관리에서 확인한 키를 인코딩해 채우세요. 비어 있으면
     *  [get]이 예외를 던집니다 — 채우지 않은 것을 배포 전에 알아채기 위한 것입니다.
     */
    private val ENCODED = byteArrayOf()

    /**
     * XOR 마스크.
     *
     * TODO: [ENCODED]와 함께 생성되는 값입니다. 한쪽만 바꾸면 키가 깨집니다.
     */
    private val MASK = byteArrayOf()

    /** 복호한 공개키를 돌려줍니다. SDK에 넘기기 직전에만 호출하세요. */
    fun get(): String {
        check(ENCODED.isNotEmpty() && MASK.isNotEmpty()) {
            "원스토어 공개키가 설정되지 않았습니다. OneStoreLicenseKey 의 TODO 를 채우세요."
        }

        val decoded = ByteArray(ENCODED.size) { index ->
            (ENCODED[index].toInt() xor MASK[index % MASK.size].toInt()).toByte()
        }
        return String(decoded, Charsets.US_ASCII)
    }
}
